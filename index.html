Koordinasi Tim Game Jam

Dashboard internal untuk tracking tugas & progres tim Game Jam

INFO UMUM

Apa fungsi web ini?

Web ini digunakan sebagai dashboard internal tim selama Game Jam. Fokus utama web ini adalah tracking tugas dan status per role, bukan sebagai alat komunikasi utama.

Cara Menggunakan Web Ini (Step-by-Step)

  1. Cek tugas masing-masing role
    Masuk ke tab Role & Tugas, lalu buka role kamu. Di sana ada checklist dan catatan tugas yang harus dikerjakan.
  2. Update progres lewat checklist
    Centang checklist saat tugas sudah dikerjakan. Tambahkan checklist baru jika ada tugas tambahan yang relevan dengan role tersebut.
  3. Gunakan message hanya untuk penekanan singkat
    Message digunakan untuk:
    • reminder
    • status singkat
    • catatan penting
    Bukan untuk diskusi panjang.
  4. Semua komunikasi utama tetap lewat Discord
    Diskusi, tanya jawab, brainstorming, dan koordinasi harian WAJIB dilakukan di Discord, bukan di web ini.
  5. Sharing file & materi TIDAK lewat web ini
    Semua file seperti:
    • asset
    • script
    • program
    • dokumen
    dibagikan melalui Discord atau GitHub, bukan melalui message di web ini.

Penekanan Penting

  • Web ini = tracking & transparansi progres
  • Discord = komunikasi & diskusi
  • GitHub = kode & file proyek

Gunakan masing-masing sesuai fungsinya agar kerja tim tetap rapi dan efisien.

Hari 0–1

Penentuan Arah

  • Tema diumumkan
  • Menentukan scope final (apa yang dibuat & apa yang TIDAK dibuat)
  • Core gameplay sudah bisa dimainkan, meskipun masih sangat sederhana
Target: game sudah “hidup”, bukan masih konsep
Hari 2–3

Stabilisasi Gameplay

  • Gameplay distabilkan (kontrol, aturan main, alur)
  • Art dan audio mulai diintegrasikan
  • Game sudah bisa dimainkan dari awal sampai akhir
Target: ada game utuh, walau belum cantik
Hari 4–5

Polish & Penyempurnaan

  • Fokus ke polish (feel bermain, visual clarity, audio feedback)
  • Buang fitur yang tidak penting
  • Perbaiki rasa bermain (game feel)
Target: game terasa enak dimainkan, bukan sekadar jalan
Hari 6

Finalisasi

  • Bug fixing (prioritas bug besar)
  • Finalisasi visual, audio, dan credits
  • Rekam video highlight
Target: tidak ada perubahan besar setelah hari ini
Hari 7

Submission

  • Build final
  • Upload ke itch.io
  • Submit game
Target: submit tepat waktu, bukan sempurna tapi terlambat

Pilih role untuk fokus mengerjakan tugas atau lihat semua role untuk overview.
